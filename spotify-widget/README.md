# Spotify Spin Widget

Spotify에서 지금 재생 중인 곡을 보여주는 정사각형 데스크톱 위젯이에요.

- 가운데 LP판 위에서 앨범 커버가 돌아가고, 일시정지하면 멈춰요.
- 곡이 바뀌면 화면 오른쪽 위에 같은 모양의 카드가 알림처럼 슬라이드로 나타났다가 4.5초 뒤에 사라져요.
- 위젯은 마우스로 끌어서 옮길 수 있어요. 우클릭하면 항상 위에 표시, 알림 미리보기, 로그아웃, 종료 메뉴가 나와요.
- **LP 효과**: 재생하면 톤암이 판 위로 내려오고, 곡이 진행될수록 바늘이 안쪽으로 조금씩 움직여요. 일시정지하면 판이 천천히 멈추고 톤암이 들려요. 곡이 바뀌면 판을 빼고 새 판을 끼우는 애니메이션이 나와요.
- **앨범커버 색 테마**: 커버의 대표 색으로 진행바, 이퀄라이저, 테두리, 가사 색이 곡마다 바뀌어요.
- **재생 컨트롤**: 위젯에 마우스를 올리면 이전 곡 / 재생·일시정지 / 다음 곡 버튼이 나와요. 오른쪽 위 ♥로 좋아요를 누르거나 취소할 수 있어요.
- **실시간 가사**: 곡 정보 위에 지금 부르는 가사 한 줄이 노래에 맞춰 바뀌어요. 가사는 [LRCLIB](https://lrclib.net)에서 가져오고, 없으면 앨범 이름이 나와요.

## 카프리 칩 (사이버펑크: 엣지러너 2)

- 엣지러너 2 곡을 틀면 화면 위에서 빨간 엔그램 칩이 위젯 오른쪽으로 떨어져요(자리가 없으면 왼쪽). 이렇게 판단해요.
  - 앨범명이나 곡명에 `Edgerunners 2`가 들어간 곡
  - `chip-songs.json`에 있는 곡: 엣지러너 2에 나온 곡 목록이에요. 오프닝 The Cure "10:15 Saturday Night", 팬텀 리버티 OST "Hardest to Be", 싱글로 나온 곡, 스코어까지 들어 있어요. 제목과 가수가 둘 다 맞아야 해요.
- 칩은 옆으로 누운 채(단자가 왼쪽) 떨어져요. USB처럼 직접 꽂아야 해요.
  - 끌어도 위젯 위로 지나가지 못하고 가장자리에 막혀요. 반대편으로 가려면 위젯을 돌아가야 해요.
  - 위젯 오른쪽 가운데 홈 높이에 맞추면 칩이 홈에 착 붙고, 그대로 왼쪽으로 밀면 들어간 만큼 위젯에 가려져요. 끝까지 밀면 '딸깍' 꽂혀요. 덜 넣고 놓으면 튕겨 나와요.
  - 꽂히면 오른쪽 홈에서 번개가 쏟아지고, 화면이 흔들리고, `CAPRI // ENGRAM LINKED`가 떠요. 그 뒤로는 위젯이 빨갛게 바뀌고 가끔 번개가 찌릿찌릿 튀어요.
  - 꽂힌 칩은 끝부분이 위젯 옆에 튀어나와 보여요. 위젯을 옮기면 같이 따라와요.
  - 튀어나온 끝을 잡고 오른쪽으로 끝까지 당기면 빠져요(카프리 연출 끝). 덜 당기고 놓으면 다시 쏙 들어가요.
- 다른 곡으로 넘어가면 칩이 자동으로 빠져요.
- 우클릭 메뉴의 **카프리 칩 떨어뜨리기 / 뽑기**로 아무 때나 해볼 수 있어요.
- 칩이 떨어질 곡을 바꾸려면 `config.json`에 키워드를 넣으면 돼요(앨범명이나 곡명에 포함되면 떨어짐).
  ```json
  { "clientId": "...", "chipKeywords": ["edgerunners 2", "you can't run from me"] }
  ```
- 칩 그림과 번개 효과는 작품 이미지를 가져온 게 아니라, 그 분위기를 참고해서 새로 그린 거예요.
- 칩을 꽂으면 빨간 홀로그램 카프리 잔상이 지직거리며 나타났다가, 가로로 썰리듯 위로 흩어져 사라져요. 기본 실루엣은 직접 그린 상반신이고, 이 폴더에 `capri.png`를 넣으면 그 이미지로 잔상을 만들어요(배경 투명 PNG 추천).
- 원하는 칩 이미지가 있으면 이 폴더에 `chip.png`로 저장하세요. 그러면 그려둔 칩 대신 그 이미지가 떨어져요(배경이 투명한 PNG를 추천해요).

## 산데비스탄 (사이버펑크: 엣지러너 1)

- 엣지러너 1 곡이 나오면 위젯 오른쪽 위에 **SANDY** 버튼이 생겨요. 이렇게 판단해요.
  - 앨범명에 `Edgerunners`가 있고 `Edgerunners 2`는 아닌 곡
  - `sandy-songs.json`에 있는 곡: 엣지러너 1 에피소드에 나온 곡 목록이에요. 게임 라디오 앨범이나 싱글로 들어도 켜져요. 제목과 가수가 둘 다 맞아야 해서 너바나의 "Lithium" 같은 동명곡은 걸리지 않아요.
  - 빠진 곡이 있으면 `sandy-songs.json`에 `{ "title": "곡 제목", "artists": ["가수"] }`를 추가하면 돼요.
- 누르면 먼저 위젯 가운데에 척추 임플란트가 나타나서 아래 마디부터 위로 초록 불이 차례로 들어와요. 다 켜지면 왼쪽 가장자리로 붙어서 깜빡이고, 끝날 때는 위에서부터 불이 꺼져요.
- 척추가 켜지는 동안 뒤에 등 이미지(`sandy-back.png`)가 꽉 차게 깜빡이며 보이고, 다 켜지면 흰·초록 섬광과 함께 시작해요. 켜져 있는 동안엔 그 이미지가 은은하게 숨쉬듯 비쳐요.
- 그 다음 10초 동안 산데비스탄이 켜져요. 판이 지나간 자리마다 멈춘 잔상이 계속 찍혔다 사라지고, 위젯 전체가 분홍·초록으로 갈라지며 테두리가 무지개색으로 돌아요. 끝나면 시간이 확 돌아오듯 화면이 번쩍해요. 초록 링이 퍼지고, 판이 느려지면서 좌우로 움직이고, 초록·노랑·분홍·보라색 잔상이 따라와요. 위쪽에는 남은 시간 게이지가 나와요.
- 끝나면 4초 동안 다시 쓸 수 없어요.
- 우클릭 메뉴의 **산데비스탄 켜기**로 아무 곡에서나 해볼 수 있어요.
- 켜지는 곡을 바꾸려면 `config.json`에 `"sandyKeywords": ["..."]`를 넣으세요.
- 실제 Spotify 재생 속도는 바뀌지 않고, 위젯 화면만 느려지는 연출이에요.

## 노치 모드

- 위젯을 우클릭해서 **노치 모드**를 켜면 위젯이 맥북 화면 위 노치 자리로 옮겨가요. 다시 누르면 원래 떠 있는 위젯으로 돌아가고, 원래 있던 위치도 기억해요.
- 평소엔 노치 양옆에 작게 붙어 있어요. 왼쪽엔 돌아가는 앨범커버, 오른쪽엔 이퀄라이저가 보여요. 그 외 부분은 클릭이 뒤로 통과해서 메뉴바를 그대로 쓸 수 있어요.
- 곡이 있으면 접혀 있어도 노치 아래로 살짝 늘어난 줄에 지금 부르는 가사가 보여요. 가사가 없는 곡이면 제목 · 가수가 나와요(일시정지해도 모양은 그대로).
- 마우스를 올리면 노치에서 아래로 펼쳐져 LP·가사·재생 버튼·브레인댄스를 다 쓸 수 있어요. 마우스를 치우면 다시 접혀요.
- 곡이 바뀌면 오른쪽 위 알림 대신 노치가 4.5초 동안 펼쳐졌다 접혀요.
- 카프리 칩은 펼쳐진 카드의 오른쪽 홈에 꽂아요. 칩이 떨어져 있거나 꽂는 중엔 접히지 않고, 꽂힌 칩 끝은 펼쳐져 있을 때만 보여요.
- 노치 모드에선 위젯을 끌어서 옮길 수 없어요. 노치 너비가 맞지 않으면 `config.json`에 `"notchWidth": 200`처럼 넣어 조절하세요.

## 브레인댄스

- 위젯 맨 아래 진행바를 마우스로 잡고 끌면 브레인댄스 편집기가 열려요.
- 좌우로 끌면 그 시점의 가사와 시간이 보이고, 아래 타임라인(VISUAL / AUDIO / THERMAL 레이어)에 재생헤드가 움직여요. 점선은 지금 실제로 재생 중인 위치예요.
- 손을 떼면 Spotify가 그 위치로 이동하고 편집기가 닫혀요. 편집기 안의 타임라인을 다시 잡아서 계속 훑을 수도 있어요. ESC나 다른 곳을 누르면 이동하지 않고 닫혀요.
- 위치 이동도 재생 조작이라 Spotify Premium에서만 돼요.

## 효과음

- 소리 파일 없이 코드로 직접 만든 효과음이 나와요: 칩 떨어질 때 금속음, 꽂힐 때 '치이익-철컥', 꽂는 순간 번개 '지지직'(평소에 튀는 작은 번개는 소리 없음), 카프리 잔상 디지털 잡음, 척추 마디 켜질 때 '틱틱틱'과 떨리며 치솟는 높은 음, 산데비스탄 발동 때 메아리치는 '팅' + 늘어지며 떨어지는 음 + 깊은 '쿵', 켜져 있는 동안 낮은 '우웅'과 느린 심장 소리, 끝날 때 '휙', 브레인댄스 신호음과 끌 때 '틱'.
- 우클릭 메뉴의 **효과음**으로 켜고 끌 수 있고, 설정은 기억돼요.
- 산데비스탄 소리를 직접 고른 파일로 바꾸려면 이 폴더에 `sandy-on.mp3`(켤 때), `sandy-off.mp3`(끝날 때)를 넣으세요. `.wav`, `.m4a`도 돼요.
  - 지금은 `sandy-on.mp3`가 들어 있어서, SANDY를 누르자마자 그 소리가 나요(척추 '틱틱틱'과 만든 발동음은 생략). 낮은 '우웅'과 심장 소리는 그 소리가 끝난 뒤에 깔려요. 파일을 지우면 만든 소리로 돌아가요.

## 1. Spotify 앱 만들기 (처음 한 번만)

1. https://developer.spotify.com/dashboard 에 로그인한 뒤 **Create app**을 눌러요.
2. **Redirect URI**에 아래 주소를 정확히 똑같이 넣어요.
   ```
   http://127.0.0.1:8888/callback
   ```
   (`localhost`는 Spotify가 받지 않으니 꼭 `127.0.0.1`로 써야 해요.)
3. API는 **Web API**를 선택하고 저장해요.
4. 앱 설정 화면에 있는 **Client ID**를 복사해요. Client Secret은 필요 없어요(PKCE 방식).
5. `config.example.json`을 `config.json`으로 복사하고 거기에 붙여넣어요.
   ```json
   { "clientId": "여기에_Client_ID" }
   ```

## 2. 실행

```bash
npm install
npm start
```

위젯에서 **Spotify 로그인**을 누르면 브라우저가 열려요. 거기서 허용하면 연결이 끝나요.
로그인 정보는 저장되기 때문에 다음 실행부터는 바로 연결돼요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.js` | 창 생성, Spotify 로그인(PKCE), 1.5초마다 재생 정보 확인, 곡 변경 시 알림 표시 |
| `widget.html` | 위젯과 알림이 함께 쓰는 화면 (`?mode=widget` / `?mode=popup`) |
| `preload.js` | 화면과 메인 프로세스를 잇는 IPC 연결 |
| `chip.html` | 떨어지는 카프리 칩 창 |
| `lightning.js` | 위젯과 칩이 같이 쓰는 빨간 번개 그리기 |
| `sfx.js` | 코드로 만드는 효과음 |
| `sandy-songs.json` | 산데비스탄이 켜지는 엣지러너 1 곡 목록 |
| `chip-songs.json` | 카프리 칩이 떨어지는 엣지러너 2 곡 목록 |

## 바꾸고 싶을 때

- 알림 표시 시간: `widget.html`의 `SHOW_MS`
- LP 회전 속도: `widget.html`의 `RPM_DEG` (1초에 도는 각도)
- 위젯/알림 크기: `main.js`의 `WIDGET_SIZE`, `POPUP_SIZE`
- 알림 위치 여백: `main.js`의 `POPUP_MARGIN`

## 참고

- 재생 조작과 좋아요 기능이 생기면서 Spotify 권한이 늘었어요. 이전 버전에서 로그인했다면 위젯에 "다시 로그인해 주세요"가 한 번 나와요.
- 이전/다음/재생/일시정지는 Spotify **Premium** 계정에서만 돼요. 무료 계정이면 위젯에 안내가 잠깐 떠요.

- Linux에서 배경이 투명하게 나오지 않으면 `npm start -- --enable-transparent-visuals --disable-gpu`로 실행해 보세요.
- 개발 모드 Spotify 앱은 대시보드의 **User Management**에 등록한 계정만 쓸 수 있어요. 앱을 만든 본인 계정은 바로 쓸 수 있어요.
